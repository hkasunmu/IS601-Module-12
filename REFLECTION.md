# Module 12 Reflection 
For Module 12, I learned how to add user registration, login, and calculation routes to my FastAPI calculator. This assignment helped me understand how everything I worked on in the previous modules connects together.

One of the things I learned was how users can register and log in while keeping their passwords secure. I also worked with calculation routes that allow users to add, view, update, and delete calculations.

The biggest challenge I faced was getting everything to work correctly with Docker and GitHub Actions. At first, Docker Desktop would not start, so I had to fix that before continuing. Another issue happened when GitHub Actions failed because my Docker Hub login information was missing. After correcting the settings, I was able to get the workflow to pass.

I also learned how important integration testing is because it helps make sure different parts of the application work together. I successfully ran 26 tests locally, and they all passed.

Overall, this assignment was challenging, but I learned a lot about building APIs, testing my code, and using GitHub Actions for deployment. I am becoming more comfortable with these tools compared to when I first started.
